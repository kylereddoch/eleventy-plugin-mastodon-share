# Contributing

Thanks for your interest in contributing to `eleventy-plugin-mastodon-share`.

## Ways to Help

- report bugs
- suggest improvements
- improve documentation
- add tests
- submit code changes

## Local Setup

Install dependencies:

```bash
npm install
npm --prefix demo install
```

Run verification:

```bash
npm run verify
```

## Pull Requests

When opening a pull request:

- keep the change focused
- describe what changed and why
- update the README when the public API changes
- add or update tests when behavior changes
- avoid unrelated refactors unless they are necessary for the fix

## Questions

If you are unsure where to start, open an issue and describe the problem or idea first.
