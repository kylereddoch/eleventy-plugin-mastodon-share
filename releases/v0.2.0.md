# v0.2.0

This release turns `eleventy-plugin-mastodon-share` into a more complete, production-ready Eleventy plugin.

## Highlights

- Added a cleaner share flow for Mastodon instance selection
- Added `mastodonSharePost` for easier post-level integration
- Added support for Nunjucks, Liquid, and Eleventy JavaScript templates
- Added support for both ESM and CommonJS consumers
- Improved the default UI and saved-instance experience
- Added CI, npm trusted-publishing workflow support, and release helpers
- Reworked the README and demo for clearer adoption

## Verification

- `npm run verify`
- CommonJS package loading check
- ESM package loading check

## Notes

- No known breaking changes for current ESM consumers
- CommonJS support is now available for projects still using `.eleventy.js`
